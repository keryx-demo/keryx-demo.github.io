Keryx protocol — local demo

Demonstration of a signed company-to-user broadcast channel, served from this directory. All URLs point at https://v1b3coder.github.io/keryx-demo; this demo is not published by Trezor.

  • Generic join link — no payload, static, for anyone (QR code rendered on the page)
  • Demo join link — with suggested public channels and a private capability feed (QR code rendered on the page; the URL is also in join.txt)
  • .well-known/keryx/root.json (root anchor on the join origin; the ONLY root metadata source)
  • keryx/targets.json (channel authorization + editor mode + private patterns)
  • keryx/channels.security.json (channel role metadata pins channels/security/feed.json)
  • channels/security/feed.json (signed public feed)
  • _sig extension
  • Announcements
