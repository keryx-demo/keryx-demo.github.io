Keryx protocol — local demo

Demonstration of a signed company-to-user broadcast channel, served from this directory. All URLs point at https://keryx-demo.github.io; this demo is not published by Trezor.

  • Generic join link — no payload, no suggested channels or private feeds (pairs with the public channels; QR rendered on the page)
  • Demo join link — with suggested public channels and a private capability feed (QR code rendered on the page; the URL is also in join.txt)
  • .well-known/keryx/root.json (root anchor on the join origin; the ONLY root metadata source)
  • keryx/targets.json (channel + authors role authorization, company identity, private-feed patterns)
  • keryx/channels.security.json (channel role metadata pins the security items)
  • keryx/channels.security.authors.json (authors role metadata — authorizes item signing)
  • keryx/channels/security/msg-2026-03-18-phishing-attacks.json (one item = one TUF target)
  • Announcements (human-readable copies)
