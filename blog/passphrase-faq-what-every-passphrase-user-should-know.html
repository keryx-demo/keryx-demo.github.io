Passphrase FAQ: What every passphrase user should know

security · 2026-08-06T09:00:00Z · Trezor Team

The passphrase is a sharp tool. Used carefully, it adds real security to your wallet. Used carelessly, it's one of the fastest ways to lose access to your own crypto. Before anything else: passphrases cannot be changed or removed — if you lose yours, you lose access to the funds in that wallet. Write it down, store it safely, test it before you send anything significant.
